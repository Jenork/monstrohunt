# Иконки монстров

Поместите ваши иконки монстров в эту папку с следующими именами:

- `dragon.png` - для дракона (id: 0)
- `ogre.png` - для огра (id: 1)
- `tengu.png` - для тэнгу (id: 2)
- `alien.png` - для пришельца (id: 3)
- `robot.png` - для робота (id: 4)
- `ghost.png` - для призрака (id: 5)
- `skeleton.png` - для скелета (id: 6)
- `dinosaur.png` - для динозавра (id: 7)

## Требования к изображениям:

- Формат: PNG (рекомендуется) или другой формат, поддерживаемый браузером
- Размер: рекомендуется квадратные изображения (например, 64x64, 128x128 или больше)
- Прозрачный фон предпочтителен для лучшего отображения

## Размеры отображения:

- В карточках монстров: 64x64 пикселей
- В карточках охоты: 48x48 пикселей
- В выборе аватара: 32x32 пикселя

Изображения будут автоматически масштабироваться до нужного размера с сохранением пропорций.
