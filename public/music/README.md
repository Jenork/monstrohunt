# Background Music

## Добавление музыки

Поместите аудио файл с зловещей музыкой в эту папку с именем `background.mp3`.

### Рекомендации:

- **Формат**: MP3 (наиболее совместимый формат)
- **Размер**: Рекомендуется до 5MB для быстрой загрузки
- **Длительность**: Музыка будет зациклена, поэтому подойдет любая длительность
- **Громкость**: Компонент автоматически установит громкость на 50%

### Альтернативные форматы:

Если вы хотите использовать другой формат (например, `.ogg` или `.wav`), измените путь в файле `app/components/ui/BackgroundMusic.tsx`:

```tsx
src="/music/background.mp3"
```

на:

```tsx
src="/music/background.ogg"  // или другой формат
```

### Где найти зловещую музыку:

- [Freesound.org](https://freesound.org) - бесплатные звуки с лицензией Creative Commons
- [Incompetech](https://incompetech.com/music/royalty-free/) - бесплатная музыка Kevin MacLeod
- [Pixabay Music](https://pixabay.com/music/) - бесплатная музыка без авторских прав

**Поисковые запросы**: "dark ambient", "horror music", "ominous", "sinister", "eerie"
