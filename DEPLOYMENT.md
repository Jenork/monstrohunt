# 🚀 Deployment Guide - MONSTROHUNT

Приложение рассчитано на **Base App only** (Mini App). Кошелек подключается только при открытии в Base App.

## ✅ Текущий статус

Приложение готово к деплою:
- ✅ Смарт-контракт реализован (FINAL ECONOMY v1.3)
- ✅ Фронтенд готов
- ✅ UI/UX оптимизирован
- ✅ Обработка ошибок добавлена

## 📋 План действий

### Шаг 1: Локальное тестирование

1. **Проверьте работу приложения локально:**
   ```bash
   npm run dev
   ```
   - Откройте http://localhost:3000
   - Проверьте все экраны (Home, Create, Profile, Hunt, FAQ)
   - Убедитесь, что нет ошибок в консоли

2. **Проверьте компиляцию контракта:**
   ```bash
   npm run compile
   ```
   - Убедитесь, что нет ошибок компиляции

### Шаг 2: Подготовка к деплою

1. **Настройте переменные окружения:**
   
   Откройте `.env` и убедитесь, что указаны:
   ```env
   BASE_SEPOLIA_RPC_URL=https://sepolia.base.org
   BASE_MAINNET_RPC_URL=https://mainnet.base.org
   PRIVATE_KEY=your_private_key_here
   NEXT_PUBLIC_CONTRACT_ADDRESS=0x0000000000000000000000000000000000000000
   ```

2. **Получите тестовые ETH для Base Sepolia:**
   - Перейдите на https://www.coinbase.com/faucets/base-ethereum-goerli-faucet
   - Или используйте другой faucet для Base Sepolia
   - Убедитесь, что на кошельке есть ETH для газа

### Шаг 3: Деплой на тестовую сеть (Base Sepolia)

1. **Скомпилируйте контракт:**
   ```bash
   npm run compile
   ```

2. **Задеплойте контракт:**
   ```bash
   npm run deploy:sepolia
   ```

3. **Сохраните адрес контракта:**
   - Скопируйте адрес из вывода команды
   - Обновите `.env`:
     ```env
     NEXT_PUBLIC_CONTRACT_ADDRESS=0x...ваш_адрес...
     ```

4. **Обновите ABI (если нужно):**
   - ABI уже находится в `app/contracts/monstroHunt.ts`
   - Убедитесь, что он соответствует задеплоенному контракту

### Шаг 4: Тестирование на тестовой сети

1. **Перезапустите dev-сервер:**
   ```bash
   npm run dev
   ```

2. **Проверьте сеть Base Sepolia:**
   - Откройте приложение **внутри Base App** по задеплоенному URL
   - Кошелек подключается автоматически через Base App; при необходимости переключите сеть на Base Sepolia в настройках кошелька
   - Параметры сети: Base Sepolia, RPC https://sepolia.base.org, Chain ID 84532

3. **Протестируйте все функции:**
   - ✅ Создание монстра (выберите тир)
   - ✅ Просмотр своего монстра в Profile
   - ✅ Кормление монстра
   - ✅ Охота на голодных монстров (если есть)
   - ✅ Продажа монстра
   - ✅ Проверка cooldown при охоте

### Шаг 5: Верификация контракта (рекомендуется)

1. **Верифицируйте контракт на BaseScan:**
   - Перейдите на https://sepolia.basescan.org/
   - Найдите ваш контракт
   - Нажмите "Verify and Publish"
   - Загрузите исходный код `MonstroHunt.sol`

### Шаг 6: Деплой на Mainnet (Base)

⚠️ **ВНИМАНИЕ:** Деплой на mainnet необратим! Убедитесь, что все протестировано.

1. **Повторите шаги 2-4 для mainnet:**
   ```bash
   npm run deploy:mainnet
   ```

2. **Обновите `.env` с адресом mainnet контракта**

3. **Проведите финальное тестирование на mainnet**

### Шаг 7: Деплой фронтенда (опционально)

1. **Соберите production версию:**
   ```bash
   npm run build
   ```

2. **Деплой на Vercel (рекомендуется):**
   ```bash
   npm install -g vercel
   vercel
   ```

3. **Или используйте другой хостинг:**
   - Netlify
   - Cloudflare Pages
   - GitHub Pages

## 📝 Важные заметки

1. **Экономика финальная (v1.3)** - не изменяйте контракт после деплоя
2. **Нет upgradeability** - контракт не может быть обновлен
3. **Протокольные комиссии зафиксированы:**
   - 5% при смерти монстра
   - 1% при продаже
4. **1 wallet = 1 monster** - ограничение встроено в контракт

## 🆘 Проблемы и решения

### Ошибка компиляции
- Проверьте версию Solidity (0.8.20)
- Убедитесь, что все зависимости установлены

### Ошибка деплоя
- Проверьте баланс кошелька (нужен ETH для газа)
- Проверьте правильность PRIVATE_KEY в .env
- Убедитесь, что RPC URL правильный

### Контракт не работает на фронтенде
- Проверьте адрес контракта в .env
- Убедитесь, что ABI соответствует контракту
- Проверьте, что кошелек подключен к правильной сети
