# 🎮 Demo Mode - Имитация нескольких игроков

## ✅ Что сделано

Создана система mock данных для демонстрации приложения с несколькими игроками на локальном сервере.

## 🎯 Как это работает

**Mock режим автоматически активируется**, когда:
- `NEXT_PUBLIC_CONTRACT_ADDRESS` = `0x0000000000000000000000000000000000000000` (значение по умолчанию)
- Контракт еще не задеплоен

## 📊 Что показывается

### Hunt Screen (Охота):
- **8 mock монстров** разных игроков
- **2 starved монстра** - можно охотиться (ID 2, 3)
- **2 hungry монстра** - скоро станут starved (ID 4, 5)
- **4 fed монстра** - сытые (ID 6, 7, 8, 9)
- Ваш монстр (ID 1) не показывается в списке для охоты

### Profile Screen (Профиль):
- Показывается **ваш mock монстр** (ID 1)
- Статус: Fed (сытый)
- Есть pending rewards для демонстрации
- Можно увидеть feed cost

## 🎨 Визуальные индикаторы

- **Синее уведомление "Demo Mode"** - показывает, что используются mock данные
- Разные статусы монстров с цветовой индикацией
- Разные тиры (Scout, Hunter, Leviathan)
- Разные веса и награды

## 🔄 Переключение между режимами

### Mock режим (текущий):
```env
NEXT_PUBLIC_CONTRACT_ADDRESS=0x0000000000000000000000000000000000000000
```

### Реальный режим (после деплоя):
```env
NEXT_PUBLIC_CONTRACT_ADDRESS=0x...ваш_реальный_адрес_контракта...
```

После обновления адреса контракта mock режим автоматически отключится.

## 📝 Mock данные включают

- ✅ Разные имена монстров
- ✅ Разные тиры (Scout, Hunter, Leviathan)
- ✅ Разные статусы (fed, hungry, starved)
- ✅ Разные веса и награды
- ✅ Разные адреса владельцев
- ✅ Реалистичные feed costs
- ✅ Pending rewards для вашего монстра

## 🚀 Как посмотреть

1. Запустите dev-сервер:
   ```bash
   npm run dev
   ```

2. Откройте http://localhost:3000

3. Перейдите на вкладку **Hunt** - увидите список монстров для охоты

4. Перейдите на вкладку **Profile** - увидите ваш mock монстр

5. Обратите внимание на синее уведомление "Demo Mode"

## ⚠️ Важно

- Mock данные используются **только для демонстрации**
- В mock режиме нельзя реально охотиться или кормить (показывается уведомление)
- После деплоя контракта mock режим автоматически отключится
- Все транзакции в mock режиме будут показывать информационные сообщения
