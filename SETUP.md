# Инструкция по установке Monstro Hunt

## Проблема с правами доступа

Файлы проекта были созданы во временной директории `C:\Users\Дмитрий\MonstroHuntTemp` из-за проблем с правами доступа к исходной директории `c:\Users\Projects\MonstroHunt`.

## Решение

### Вариант 1: Скопировать файлы вручную

1. Откройте проводник Windows
2. Перейдите в `C:\Users\Дмитрий\MonstroHuntTemp`
3. Выделите все файлы и папки (Ctrl+A)
4. Скопируйте их (Ctrl+C)
5. Перейдите в `c:\Users\Projects\MonstroHunt`
6. Вставьте файлы (Ctrl+V)

### Вариант 2: Использовать PowerShell от имени администратора

1. Откройте PowerShell от имени администратора
2. Выполните команду:
```powershell
Copy-Item -Path "C:\Users\Дмитрий\MonstroHuntTemp\*" -Destination "c:\Users\Projects\MonstroHunt\" -Recurse -Force
```

### Вариант 3: Использовать проект из временной директории

Если права доступа не удается исправить, можно работать с проектом напрямую из `C:\Users\Дмитрий\MonstroHuntTemp`.

## После копирования файлов

1. Откройте проект в Cursor/VS Code
2. Установите зависимости:
```bash
npm install
```

3. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

4. Добавьте ваш приватный ключ и RPC URLs в `.env`

5. Скомпилируйте смарт-контракт:
```bash
npm run compile
```

6. Задеплойте контракт (Base Sepolia):
```bash
npm run deploy:sepolia
```

7. Обновите адрес контракта в `app/utils/contract.ts` или в `.env` как `NEXT_PUBLIC_CONTRACT_ADDRESS`

8. Запустите dev сервер:
```bash
npm run dev
```

## Примечания

- Приложение работает как стандартный web app. Для лучшего mobile UX можно открывать задеплоенный URL в Base App, но обычный браузер тоже поддерживается.
- Убедитесь, что у вас установлен Node.js 18+
- Для деплоя нужен приватный ключ с ETH на Base Sepolia
- После деплоя обновите адрес контракта в коде
