# Инструкция по запуску сервера

## Проблема с путем

Из-за кириллицы в пути пользователя (`Дмитрий`) могут возникнуть проблемы с выполнением команд через терминал.

## Решение 1: Использовать bat файл

1. Откройте проводник Windows
2. Перейдите в `C:\Users\Дмитрий\MonstroHuntTemp`
3. Дважды кликните на файл `start.bat`
4. Дождитесь установки зависимостей и запуска сервера

## Решение 2: Использовать PowerShell напрямую

1. Откройте PowerShell
2. Выполните команды:

```powershell
cd "C:\Users\Дмитрий\MonstroHuntTemp"
npm install --legacy-peer-deps
npm run dev
```

## Решение 3: Использовать CMD

1. Откройте CMD (командную строку)
2. Выполните команды:

```cmd
cd "C:\Users\Дмитрий\MonstroHuntTemp"
npm install --legacy-peer-deps
npm run dev
```

## После запуска

Сервер будет доступен по адресу: http://localhost:3000

Откройте браузер и перейдите по этому адресу.

## Примечания

- Убедитесь, что у вас установлен Node.js 18 или выше
- Первая установка зависимостей может занять несколько минут
- Если возникнут ошибки с зависимостями, попробуйте удалить `node_modules` и `package-lock.json` и запустить установку заново
